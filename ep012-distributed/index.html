    We pretrain a model about six times bigger, in GPT-2 small's shape, on four RTX 4090s rented by the hour, with PyTorch's DistributedDataParallel, and measure how the speed scales from one GPU to four, and how much better the model gets in thirty minutes.

    Data parallelism

    2:21 The paper is PyTorch Distributed: Experiences on Accelerating Data Parallel Training, from 2020, by Shen Li and others at Facebook, who built PyTorch's distributed data parallel module. Its abstract describes the technique: each GPU holds a copy of the model and computes gradients on its own data, then the GPUs exchange those gradients at each step, so that the copies stay consistent. Configured well, it scaled almost linearly, up to two hundred and fifty-six GPUs. Figure four shows two processes, each with a copy of a small model. As the backward pass goes from the loss back up the layers, the gradients are copied into buckets, and as soon as a bucket is full, an all-reduce, in red, averages it across the processes, while the layers before it are still computing theirs.

    3:08 With data parallelism, each GPU holds a whole copy of the model, and trains it on batches of its own, so four GPUs read four times as many stories in each step.
