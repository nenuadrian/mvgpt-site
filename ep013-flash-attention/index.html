Flash attention from scratch: PyTorch, Triton

We write attention without its table of scores, first in PyTorch on the Mac, then as a Triton kernel on a rented NVIDIA GPU, forwards and backwards, and measure it against the FlashAttention-2 inside PyTorch.

Watch on YouTube

Attention as the paper writes it keeps a table of scores that grows with the square of the length, so in this episode we write flash attention, which computes it a block at a time. We start with attention by hand and its memory on the Mac, then write the online softmax in PyTorch, and then as a Triton kernel on a rented RTX 4090. And we measure our kernel against FlashAttention-2, which PyTorch already runs on NVIDIA GPUs, and pretrain the model with each.
