Deploy a GPT: Hugging Face, Gradio, a browser

We save our model as a GPT-2 and push it to the Hugging Face Hub, with a tag per episode, serve it from a Gradio app on a VPS, and run it in the browser with Transformers.js.

Watch on YouTube

This time, we deploy our model, first to the Hugging Face Hub as a GPT-2 that transformers can load, with a tokenizer.json, an 8-bit ONNX export and a tag per episode. Then a Gradio app loads each version from the Hub and writes stories, on my machine and in Docker on a VPS, deployed over SSH. And a single web page runs the model in the browser with Transformers.js, downloading it when you ask for a story.
