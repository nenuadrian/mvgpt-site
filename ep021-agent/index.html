    AI agent from scratch, with subagents

    We fine-tune our web model into an agent that writes files and hands work to subagents, each a fresh context of the same model, and measure what the subagents buy.

    Watch on YouTube

    In this episode, our model becomes an agent, fine-tuned once into three roles: the agent, which hands parts of a task to subagents, a math role with the calculator, and a files role in a sandbox. Each subagent works in a fresh context, and its answer is all that goes back to the agent. We fine-tune for thirty minutes on the laptop, measure each role on held-out tasks, compare subagents with one long context, and put the agent in a Gradio chat that shows each step.

    Wrap-up

    20:54 Now, let's go over what's real here, and what's scaled down.
