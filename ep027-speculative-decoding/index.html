    Speculative decoding from scratch

    A draft guesses the next few tokens, and our agent checks them in the pass that writes its own, so it writes what greedy decoding writes in fewer passes. Two drafts, prompt lookup and a small model trained for thirty minutes, measured on the agent's tasks.

    Watch on YouTube

    In this episode, our agent writes its answers word for word as before, in fewer passes of the model. A pass on the Mac's GPU costs about the same for a few tokens as for one, so a cheap draft guesses the next few tokens, and the model checks them in the pass that writes its own, keeping the guesses up to the first it disagrees with. We build speculative decoding from scratch, with two drafts: prompt lookup, which guesses what the text copies for nothing, and a small model of four layers, trained for thirty minutes on the agent's tasks. Then we measure both on episode twenty-five's held-out tasks: the passes, the guesses kept, the time, and whether the text is the same.
